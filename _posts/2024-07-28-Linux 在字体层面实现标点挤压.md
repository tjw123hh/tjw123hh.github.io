## 若使用 Noto CJK

由于我使用的是 Noto CJK 字体，所以我给字体加上字体特性后打包成了两个新字体（同时包含 Sans 和 Serif）：[noto-cjk-chws](https://github.com/tjw123hh/noto-cjk-chws) 和 [noto-cjk-chws-patch](https://github.com/tjw123hh/noto-cjk-chws-patch)。其中 `noto-cjk-chws` 是可以把原有的字体替换，但字体非常大；而 `noto-cjk-chws-patch` 只保留了其中的更改的标点部分和“—”（因此在 fontconfig 中需要排在原字体之前），且可以通过在 patch 和原 Noto CJK 字体之间夹一个英文字体来更改英文字体并不影响引号、撇号与间隔号（“·”）的显示。如果你正在使用 Arch Linux，可以分别通过 AUR 包 `noto-fonts-cjk-chws`（直接替换 `noto-fonts-cjk` 包）与 `noto-fonts-cjk-chws-patch`（需手动配置 fontconfig）直接安装。使用说明我的存储库里有，这里不再赘述。

## 使用其他字体

如果字体本身支持 `chws` 和 `vchw` 特性（极少），直接改 fontconfig 在字体 `fontfeatures` 属性中加入就好。

示例（`~/.config/fontconfig/fonts.conf`，`<fontconfig>` 元素中）：
```xml
    <match target="font">
        <test name="family">
            <string>*你的字体名称*</string>
        </test>
        <edit binding="strong" name="fontfeatures">
            <string>chws</string>
            <string>vchw</string>
        </edit>
    </match>
```

如果字体不支持这些特性，需要利用 [chws_tool](https://github.com/googlefonts/chws_tool)（基于 [east_asian_spacing](https://github.com/kojiishi/east_asian_spacing)）手动加入。如果是 Google Fonts 中的字体，安装后直接执行 `add-chws `＋字体路径就行，如果不是，则在 `src/chws_tool/config.py` 的 `_get_factory_by_name` 函数加入自己字体的 `config`（其实一般不用加直接用 `default` 就行）。

另外如果需要子集化字体的话可以使用 `fontTools` 子集化的同时更改字体名称。我的 `subsetter.py` 的代码如下：

```python
#!/usr/bin/env python3

from fontTools.ttLib import TTFont, TTCollection
from fontTools.subset import Subsetter
import sys

subsetter = Subsetter()
subsetter.populate(text="‘“〈《「『【〔〖〘〚〝（［｛｟（［·‧・；：’”〉》」』】〕〗〙〛〞〟）］｝｠、。，．！？）］—")

tran = {
    "Noto Sans CJK": "Noto Sans CJK CHWS Patch",
    "Noto Sans Mono CJK": "Noto Sans Mono CJK CHWS Patch",
    "Noto Serif CJK": "Noto Serif CJK CHWS Patch",
    "Noto Sans": "Noto Sans CHWS Patch",
    "Noto Sans Mono": "Noto Sans Mono CHWS Patch",
    "Noto Serif": "Noto Serif CHWS Patch",
    "NotoSansCJK": "NotoSansCJKChwsPatch",
    "NotoSansMonoCJK": "NotoSansMonoCJKChwsPatch",
    "NotoSerifCJK": "NotoSerifCJKChwsPatch",
    "NotoSans": "NotoSansChwsPatch",
    "NotoSansMono": "NotoSansMonoChwsPatch",
    "NotoSerif": "NotoSerifChwsPatch"
    }

def namer(arg):

    if type(arg) == bytes:
        return namer(arg.decode("utf-16-be")).encode("utf-16-be")
    if type(arg) == str:
        for before in tran:
            if tran[before] in arg:
                return arg
            elif before in arg:
                return arg.replace(before, tran[before])
    return arg

def list_namer(li):
    for i in range(len(li)):
        li[i] = namer(li[i])

def dict_namer(di):
    for k in di:
        di[k] = namer(di[k])

def modify(font):
    subsetter.subset(font)

    for record in font['name'].names:
        record.string = namer(record.string)

    if "CFF " in font.keys():
        cff = font["CFF "].cff
        list_namer(cff.strings.strings)
        list_namer(cff.fontNames)
        for dic in cff:
            dict_namer(dic.rawDict)
            dic.FamilyName = namer(dic.FamilyName)
            dic.FullName = namer(dic.FullName)


path = sys.argv[1]

if path.endswith("ttc"):
    ttc = TTCollection(path)
    for font in ttc:
        modify(font)
    ttc.save(namer(path))
else:
    font = TTFont(path)
    modify(font)
    font.save(namer(path))
```

## 局限性

用这种方式可以完美地解决字与字之间的标点挤压，但其实行首和行尾的标点也应该实现标点挤压，但这些挤压（至少目前）不能够从字体层面解决，只能通过软件或者字体渲染库的适配（安卓端的微信实现了，但只是在发送和接收的消息中）。

## 与[现行国标（GB/T 25834—2011）](http://c.gb688.cn/bzgk/gb/showGb?type=online&hcno=22EA6D162E4110E752259661E1A0D0A8)不符

### 行首、行尾的标点

见[#局限性](#局限性)。

### 叠用的问号、叹号

> 5.1.2　问号、叹号均置于相应文字之后，占一个字位置，居左，不出现在一行之首。**两个问号（或叹号）叠用时，占一个字位置**；三个问号（或叹号）叠用时，占两个字位置；**问号与叹号连用时，占一个字位置**。

对于加粗部分（使用全角符号直接叠用），在添上 `chws` 特性后，均显示为 1.5 个汉字位置。［这不比国标的规定好看？但国标就是这么规定的，虽然一个[新的国标（计划号 20240034-T-360）](https://std.samr.gov.cn/gb/search/gbDetailed?id=14CA9D282E0A5AC8E06397BE0A0AEA2E)正在起草。］

### 间隔号（“·”）

> 5.1.7　间隔号标在需要隔开的项目之间，**占半个字位置**，上下居中，不出现在一行之首。

根据 W3C 的[中文排版需求](https://www.w3.org/International/clreq/#indication_punctuation_marks)，间隔号为 `U+00B7 MIDDLE DOT`\[·\]。而日本使用来自日文 JIS 编码的 `U+30FB KATAKANA MIDDLE DOT`\[・\]，需占全宽，`U+00B7 MIDDLE DOT`\[·\]在日文排版中用于英文或数字中，应与英文相适应。

这里国标要求半个汉字宽，台湾、香港要求占全宽。这其实只与字体有关，例如在 Noto Sans CJK SC 中，该间隔号占一个汉字位置（与 TC、HK 变体相同，KR、JP 变体约占半个汉字位置）；Noto Serif CJK SC 中，该间隔号（其他变体也如此，与台湾、香港的需求不符）。但一个字宽的间隔号可能更加适合中文（毕竟大部分中文字体都这么做的）。
