## 若使用 Noto CJK

由于我使用的是 Noto CJK 字体，所以我给字体加上字体特性后打包成了两个新字体（同时包含 Sans 和 Serif）：[noto-cjk-chws](https://github.com/tjw123hh/noto-cjk-chws) 和 [noto-cjk-chws-patch](https://github.com/tjw123hh/noto-cjk-chws-patch)。其中 `noto-cjk-chws` 是可以把原有的字体替换，但字体非常大；而 `noto-cjk-chws-patch` 只保留了其中的更改的标点部分和“—”（因此在 fontconfig 中需要排在原字体之前），且可以通过在 patch 和原 Noto CJK 字体之间夹一个英文字体来更改英文字体并不影响引号、撇号与“‧”（HYPHENATION POINT）的显示。如果你正在使用 Arch Linux，可以分别通过 AUR 包 `noto-fonts-cjk-chws`（直接替换 `noto-fonts-cjk` 包）与 `noto-fonts-cjk-chws-patch`（需手动配置 fontconfig）直接安装。使用说明我的存储库里有，这里不再赘述。

## 使用其他字体

如果字体本身支持 `chws` 和 `vchw` 特性（极少），直接改 fontconfig 在字体 `fontfeatures` 属性中加入就好。

示例（`~/.config/fontconfig/fonts.conf`，`<fontconfig>` 元素中）：
```xml
    <match target="font">
        <test name="family">
            <string>*你的字体名称*</string>
        </test>
        <edit binding="strong" name="fontfeatures">
            <string>chws</string>
            <string>vchw</string>
        </edit>
    </match>
```

如果字体不支持这些特性，需要利用 [chws_tool](https://github.com/googlefonts/chws_tool)（基于 [east_asian_spacing](https://github.com/kojiishi/east_asian_spacing)）手动加入。如果是 Google Fonts 中的字体，安装后直接执行 `add-chws `＋字体路径就行，如果不是，则在 `src/chws_tool/config.py` 的 `_get_factory_by_name` 函数加入自己字体的 `config`（其实一般不用加直接用 `default` 就行）。

另外如果需要子集化字体的话可以使用 `fontTools` 子集化的同时更改字体名称。我的 `subsetter.py` 的代码如下：

```python
#!/usr/bin/env python3

from fontTools.ttLib import TTFont, TTCollection
from fontTools.subset import Subsetter, Options
import sys

subsetter = Subsetter()
subsetter.populate(text="‘“〈《「『【〔〖〘〚〝（［｛｟（［·‧・；：’”〉》」』】〕〗〙〛〞〟）］｝｠、。，．！？）］—")

def namer(arg):
    if type(arg) == bytes:
        return namer(arg.decode("utf-16-be")).encode("utf-16-be")
    if type(arg) == str: #这里要注意一些属性里面字体名称是夹在中间的，一些属性不能出现空格，不应该`return arg + "ChwsPatch"`
        if " " in arg:
            if "CHWS Patch" in arg:
                return arg
            if "Noto Sans CJK" in arg: #这里不直接替换`CJK`是因为字体标识中可能有`CJK`
                return arg.replace("Noto Sans CJK", "Noto Sans CJK CHWS Patch")
            if "Noto Sans Mono CJK" in arg:
                return arg.replace("Noto Sans Mono CJK", "Noto Sans Mono CJK CHWS Patch")
            if "Noto Serif CJK" in arg:
                return arg.replace("Noto Serif CJK", "Noto Serif CJK CHWS Patch")
            if "Noto Sans" in arg:
                return arg.replace("Noto Sans", "Noto Sans CHWS Patch")
            if "Noto Sans Mono" in arg:
                return arg.replace("Noto Sans Mono", "Noto Sans Mono CHWS Patch")
            return arg.replace("Noto Serif", "Noto Serif CHWS Patch")
        if "ChwsPatch" in arg:
            return arg
        if "NotoSansCJK" in arg:
            return arg.replace("NotoSansCJK", "NotoSansCJKChwsPatch")
        if "NotoSansMonoCJK" in arg:
            return arg.replace("NotoSansMonoCJK", "NotoSansMonoCJKChwsPatch")
        if "NotoSerifCJK" in arg:
            return arg.replace("NotoSerifCJK", "NotoSerifCJKChwsPatch")
        if "NotoSans" in arg:
            return arg.replace("NotoSans", "NotoSansChwsPatch")
        if "NotoSansMono" in arg:
            return arg.replace("NotoSansMono", "NotoSansMonoChwsPatch")
        return arg.replace("NotoSerif", "NotoSerifChwsPatch")
    return arg

def list_namer(li):
    for i in range(len(li)):
        li[i] = namer(li[i])

def dict_namer(di):
    for k in di:
        di[k] = namer(di[k])

def modify(font):
    subsetter.subset(font)

    for record in font['name'].names:
        record.string = namer(record.string)

    if "CFF " in font.keys():
        cff = font["CFF "].cff
        list_namer(cff.strings.strings)
        list_namer(cff.fontNames)
        for dic in cff:
            dict_namer(dic.rawDict)
            dic.FamilyName = namer(dic.FamilyName)
            dic.FullName = namer(dic.FullName)


path = sys.argv[1]

if path.endswith("ttc"):
    ttc = TTCollection(path)
    for font in ttc:
        modify(font)
    ttc.save(namer(path))
else:
    font = TTFont(path)
    modify(font)
    font.save(namer(path))
```

## 局限性

用这种方式可以完美地解决字与字之间的标点挤压，但其实行首和行尾的标点也应该实现标点挤压，但这些挤压（至少目前）不能够从字体层面解决，只能通过软件或者字体渲染库的适配（安卓端的微信实现了，但只是在发送和接收的消息中）。
